Google PageRank Mini

About the Project

Google PageRank Mini is a simple project that shows how web pages can be ranked based on their links.

In this project, we represent web pages and their links using a matrix. We use Eigenvectors, Eigenvalues, and Power Iteration to calculate the PageRank of each page.

How It Works

1. Create a few web pages.
2. Connect the pages using links.
3. Represent these links using a matrix.
4. Apply the PageRank calculation.
5. Use Power Iteration to find the rank of each page.
6. The page with a higher score gets a higher rank.

Mathematics Used

- Matrix
- Eigenvalues
- Eigenvectors
- Power Iteration

Objective

The main objective of this project is to understand how mathematics and programming can be used together to rank web pages.

Example

If Page A receives more important links than Page B, Page A will get a higher PageRank score.

Conclusion

This mini project gives a simple understanding of how Google's PageRank concept works using basic Linear Algebra concepts.
