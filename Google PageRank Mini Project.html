Google PageRank Mini Project

Ranking webpages using links, eigenvalues, eigenvectors and Power Iteration.

1. Input

Circles are webpages. An arrow A → B means page A links to page B. This picture updates as you type.

2. Link Matrix A

Link Matrix A represents which webpage links to which. Column j is the page that has the link, row i is the page it points to. A 1 means "there is a link".

3. Transition Matrix P

Transition Matrix P represents the probability of moving from one page to another. Each column of A is divided by its sum, so every column adds up to 1.
Dangling pages (no outgoing links) would give a column of zeros, so we replace that column by 1/n in every entry (a random jump to any page).

4. Google Matrix G

G = d·P + (1−d)/n, where d is the damping factor and n the number of pages. The (1−d)/n part is added to every entry (random surfing). All columns of G add up to 1.

5. Power Iteration calculation

Power Iteration repeatedly multiplies the Google Matrix by the rank vector until the values become stable. We start with r0 = [1/n, ..., 1/n] and compute r(k+1) = G · r(k).

6. Eigenvalues of G

An eigenvalue λ and eigenvector v satisfy G·v = λ·v. G is a column-stochastic matrix, so its largest eigenvalue is 1. The eigenvalues are found numerically (roots of the characteristic polynomial). Some may be complex numbers.

7. Eigenvector for eigenvalue 1

An eigenvector corresponding to eigenvalue 1 gives the stable PageRank vector. We solve (G − I)v = 0 numerically and scale v so its values add up to 1.

8. Final PageRank

Bigger bar = more important page. Expected behavior: the PageRank values should add up to approximately 1, and the Power Iteration result should be close to the eigenvector result.

Project Summary

Google PageRank uses matrix mathematics to measure the importance of webpages. In this project, Power Iteration finds the stable PageRank vector, while eigenvalues and eigenvectors explain the mathematical basis of the result.
